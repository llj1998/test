# 远方清单 · 使用指南

> 把零散的「想去」逐步变成真的发生过的旅行。

---

## 它是什么

想去的地方从来不缺：收藏夹里的小红书、朋友随口推荐的店、刷到的某个湖。缺的是一步步把它们变成真的出发。

远方清单是一个自己用的旅行本子。每个地方都在一条路上往前走：

| 阶段 | 样子 | 意思 | 怎么往下一格走 |
| --- | --- | --- | --- |
| ○ 想去 | 一枚邮票，面值就是想去程度（1–5 分） | 记下来了，还没打算哪天去 | 加入某次行程的某一天 |
| ◆ 计划中 | 邮票上夹了一张车票签，写着「红叶七日 · D3」 | 排进了行程 | 到了，盖章 |
| ◉ 已去过 | 盖上了带日期的邮戳 | 去过了 | 写两句、打个分、加张照片 |
| ■ 回忆 | 一张贴着照片的明信片 | 有了记录 | — |

它不只是一个收藏夹。首页会一直告诉你「下一步」：现在做哪件事，能把某个地方往前推一格。

---

## 五分钟上手

1. **打开**：双击 `远方清单.html`（或 `index.html`），用 Chrome、Edge 或 Safari 打开。第一次打开会显示一份示例数据，可以先随便点点，改坏了也没关系。
2. **决定用不用示例**：看够了就点首页顶上的「清空，开始记自己的」，在设置页确认一次。
3. **记下第一个地方**：在首页右上的「投递口」写个名字，比如 `武康路 新开的面包店`，回车。
4. **接上 AI（可选）**：进「设置 → 添加服务商」，填上你的 DeepSeek / 通义千问 / Kimi 等的接口地址、模型和密钥，点「测试连接」。
5. **以后每次打开都先看首页的「下一步」**。

数据存在你这台设备的浏览器里，不会上传。记得隔段时间在「设置 → 数据」里导出一份备份。

## 功能一览

### 1. 投递口和搜索框：记东西只要一步

记东西的入口有两个，用法一样：

- 首页右上角的**投递口**；
- 任何页面按 `/`（或 `n`），或者点侧栏 / 手机底栏的「+」，打开**搜索框**。

往里面放什么都行，它会自己判断：

| 你放进去的 | 它会做什么 |
| --- | --- |
| 一个名字，比如 `南禅寺` | 回车直接记成「想去」。类型、城市靠猜，想去程度默认 3 分 |
| 带地名的，比如 `京都 南禅寺`、`武康路 新开的面包店` | 认出城市（京都）或本地路名（武康路），常见城市自动给坐标，地图上能看到 |
| 已经记过的，比如 `稻荷` | 先把「伏见稻荷大社」列出来，避免重复；真要再记一个也可以 |
| 一条小红书分享文字（链接加标题） | 从标题里认出地点，记下来源和链接 |
| 一整段聊天记录或攻略 | 交给 AI 分拣（见「一键整理」） |

搜索框里按 `Tab` 可以展开详情：改类型、想去程度、为什么想去、标签、是否本地，左边的邮票会跟着变。

**类型是按名字里的字猜的：**

| 类型 | 名字里有这些字就会被认成它 |
| --- | --- |
| 咖啡 | 咖啡、面包、甜品、茶室、烘焙 |
| 餐馆 | 面、饭、菜、烧、火锅、生煎、小笼、寿司、市场 |
| 建筑 | 寺、宫、塔、堂、神社、桥、阁、博物馆、美术馆 |
| 自然 | 湖、山、海、公园、林、岛、瀑布、温泉 |
| 城市 | 以上都不是 |

猜错了在地点抽屉里点「改信息」就行。

### 2. 首页的「下一步」

首页最重要的就是这个列表。每一条左边都标着它把东西从哪一格推到哪一格（比如 ○→◆ 排进行程），右边是一个能直接完成它的按钮。按急不急排好了序，最急的那条按钮是红色的。

会出现在这里的事情：

| 什么时候会出现 | 按钮 |
| --- | --- |
| 正在旅行中 | 打开今天 |
| 准备事项 7 天内到期（抢票、换汇、办签证……） | 做完了 |
| 一个想去的地方季节正好，而你那时正好要去那一带 | 加进那次行程 |
| 行程还缺一步：没定日期、没订交通、没订住宿、有几天空着 | 定日期 / 订交通 / …… |
| 去过的地方还没写回忆 | 写两句 |
| 同一片地方攒了两处以上，还没有行程 | 排一次行程 |
| 城里想去的店有两家以上 | 帮我挑一个 |
| 一年多没动过的想去 | 还想去 / 放下 |

不想现在处理的，点「稍后」，它会消失一周。

首页下面还有「下一次出发」的车票，以及四个阶段各有多少个地方。

### 3. 想去：邮票册和按地方看

**邮票册**：所有地点都是邮票。

- 可以按远方 / 本地、类型、状态筛选，也可以只看「这个月适合去的」，还可以搜名称、城市、标签。
- 可以按想去程度、最近记下、名称排序。
- 鼠标移到邮票上会出现快捷按钮：加入行程、标记去过、看行程、写回忆。

**按地方**：同一趟能顺路去的地方归在一起，比如「关西」里有京都、大阪、宇治。每张卡片都会告诉你这一片的情况：

- 「还有 2 处没排进去」：点「挑进行程」。
- 「攒了 2 处，够专门跑一趟了」：点「排一次行程」，会带着这几处直接新建一次行程。
- 本地的那一片：点「帮我挑一个」。

**地点抽屉**：点任何一枚邮票都会打开它，里面有：

- 想去程度：1–5 分，点一下就改。
- 状态链：想去 → 计划中 → 已去过 → 回忆，这个地方走到了哪一步。
- 最显眼的按钮就是下一步：
  - 想去：加入行程。先选哪一次，再选哪一天；也可以「先放进来，不定哪天」，或者「为这里新建一次行程」。
  - 计划中：到了，盖章 / 换一天 / 移出行程。
  - 去过：写回忆 / 又去了一次。本地的店常常会去好几次。
- 什么时候去：12 格季节条，当前月份用红框标出。
- 为什么想去：手写体的一句话，可以直接改。还会显示是从哪里看到的（比如小红书链接）。
- 标签：可以加，也可以删。
- 改信息：名称、城市、国家、归到哪一片、类型、坐标、是否本地。
- 在地图 App 里看：国内的打开高德，国外的打开 Google 地图。
- 不想去了：放下而不是删除，在「已放下」里能找回来。

### 4. 行程

每次旅行是一张车票：目的地、日期、已订金额和预算、同行的人。

**车票下面的一排检票孔是这次旅行的进度**，根据你填的内容自动判断，不用自己填百分比：

> 定日期 → 订交通 → 订住宿 → 排日程 → 准备 → 出发

完成的是打穿的孔，下一个没完成的是红圈。点它会直接带你去完成：

| 点哪个 | 带你去哪 |
| --- | --- |
| 定日期 | 打开日期表单 |
| 订交通、订住宿 | 打开加预订的表单，类型已经选好 |
| 排日程 | 定了日期还没生成就一键生成每天，否则跳到第一天还空着的那天 |
| 准备 | 打开准备事项 |

本地一日游不需要订交通和住宿，只有定日期、排日程、准备三格。

**候选地点**：行程上方会列出「这一片还有几处想去，没排进来」。从下拉框选一天，就加进去了。

**每日安排**

- 每天可以写一个主题，比如「东山，早起看稻荷」。
- 每天底下有一行「加一项」：写 `15:30 南禅寺` 回车，就加了一个 15:30 的安排。如果名字和「想去」里的某个地方对上了，会自动关联，那个地方也会变成「计划中」。
- 拖动可以调整顺序，也能拖到另一天。
- 鼠标移上去点 × 可以移除。
- 改了行程日期，每天的安排会跟着调整。日期变短时，多出来那几天的安排会并到最后一天，不会丢。

**资料夹**：四个标签页，都能加也能删。

| 标签页 | 放什么 | 小技巧 |
| --- | --- | --- |
| 准备 | 出发前要办的事，可以打勾 | 开头写日期就会变成截止时间：`11.10 前换好日元`、`11.03 10:00 抢小火车票`。7 天内到期的会出现在首页 |
| 攻略 | 小红书、B站、公众号、官网的链接 | 粘贴分享文字就行，会自动认出来源和标题 |
| 预订 | 机票、火车、酒店、民宿、门票 | 有确认号的可以「出示」，大字显示给工作人员看。所有预订的金额会加起来，算成「已订」 |
| 备注 | 临时想到的事，和同行的约定 | 手写体显示 |

### 5. 今天：出发当天

旅行开始那天，侧栏会多出一个「今天」，首页也会提醒你打开它。

- **现在这一项**：几点开始，还有多久，怎么去。有三个按钮：到了，盖章；导航过去；出示预订。
- **下一项**：还有多久，怎么去。
- **时间线**：一条红线标出现在几点，已经盖过章的会标出来。
- **临时加一项**：写 `16:00 哲学之道` 回车。
- **今天要用的预订**：当天的门票，以及覆盖今晚的住宿。比如时间写成 `11.21 – 11.26 · 5 晚`，这几天都会显示。
- **今天花了**：按当地货币记账，并换算成人民币。分吃饭、交通、门票、购物几类。

**盖章**会弹出一张小表单，都可以不填：一句话、评分、花费、照片。只盖章也行，回头再写。写了的会直接变成一张明信片。

还没出发时，可以从行程页点「预览出发当天」看看样子。预览里盖的章不会改真实数据。

### 6. 地图

地图页有三种看法，右上角切换：

- **总览**：一张世界地图，一眼看出想去的都在哪。○ 想去、◆ 计划中、◉ 已去过，红色方块是家。虚线是计划中的航线，实线是去过的。点地图上的点，右边会列出那一片的地点。
- **细看**：真正的街道地图，可以一直放大到街区。滚轮或双指缩放，拖动平移。
  - 地点按状态画成 ○ ◆ ◉，放大以后会显示名字。点一个点打开它的抽屉。
  - **去哪一片**：点「关西」「上海」「冰岛」这些地方，地图直接飞过去，把那一片的地点都框进来。
  - **看一天的路线**：选行程里的某一天，按时间顺序把当天去的地方连起来，标上 1、2、3。右边列出每两站之间的直线距离和总距离；有一段超过 8 公里时会提醒你看看顺序。
  - **底图**：默认「自动」，在国内用高德（中文地名、路网清楚），在国外用 CARTO（基于 OpenStreetMap）。也可以固定用其中一种。
- **本地**：家所在城市的示意图。上海会画出黄浦江和苏州河，其他城市按坐标摆放。

其他地方也能直接跳到细看：

- 行程页每天的底部有「在地图上看这天」（这天有两处以上带坐标的地点时出现）。
- 「今天」页标题旁边有「看今天的路线」。
- 地点抽屉里有「在地图上看」。

**给地点定位置**：没有坐标、或者坐标只是城市中心（地图上带虚线圈）的地点，可以在抽屉里点「在地图上定位」，或在「改信息」里点「到地图上点一下」。地图会转到细看，顶部出现一条提示，在准确的位置点一下就存好了，可以撤销。也可以照旧粘贴坐标，地图 App 里长按某个位置就能复制。

没有坐标的地点不会出现在地图上。细看的街道底图要联网才能加载；没联网时地点和路线照样能看，只是背景是空白的。

### 7. 回忆

- 最上面列出「去过，还没写回忆」的地方，一处花一分钟就能补完。
- 下面按年份排着明信片：左边是照片（没有照片就用邮票图案），右边是手写的一句话、评分和花费。
- 鼠标移到明信片上点「改」，可以修改或删除。

### 8. 一键整理（AI）

把一段杂乱的内容贴进来，AI 会拆成五类：

| 格子 | 例子 |
| --- | --- |
| 行程信息 | 「预算估计要多两千」→ 预算 ¥14,000 → ¥16,000 |
| 地点 | 南禅寺 · 水路阁、鸟贵族 · 先斗町店 |
| 日程 | Day 3 15:30 南禅寺；Day 2 19:00 的晚饭改成鸟贵族 |
| 资料 | 准备：11.03 10:00 抢小火车票；攻略：一条小红书链接；备注：要提前排队 |
| 回忆 | 「上次去的那家拉面一般」→ 这家去过，2 分 |

- **已经有的会合并，不会重复创建**，会标着「合并」或「更新」。新的标着「新地点」「新增」。
- 每条都能勾掉。确认后点「写入 N 条」，写入后也能撤销。
- 「整理到」选哪次行程，日程和资料就写进哪次。选「不放进行程」的话，只整理地点和回忆。
- 换了「整理到」，会用同一份结果重新对一遍，不会重新请求 AI。

**内容从哪来**

| 来源 | 怎么做 |
| --- | --- |
| 微信 / QQ 聊天 | 长按消息，多选，复制，粘贴进来 |
| 聊天截图 | 先用手机相册或微信的「提取文字」把字取出来，再粘贴进来 |
| 小红书、公众号文章 | 复制正文粘贴进来。网页不让别的站点直接读取正文，所以光贴链接不够 |
| 自己的备忘录 | 直接粘贴 |

### 9. 设置

- **AI 服务商**
  - 可以添加多个（名称、接口地址、模型、密钥），点「设为启用」切换。
  - 「测试连接」会真的去连一次。
  - 示例里自带的三个标着「示例」，没有真的连上 AI。
- **家在哪个城市**：用来区分本地和远方，也是地图上「家」的位置。
- **数据**
  - 导出备份（JSON 文件）、复制备份内容、导入备份。
  - 载入示例数据。
  - 清空，从零开始：会先让你确认一次，清空后也能撤销。

### 10. 帮我挑一个

周末不知道去哪的时候用。

- 从城里想去的店里随机抽一家，想去程度越高越容易被抽到。
- 可以先选「吃饭 / 咖啡 / 走走」，只在这一类里抽。
- 不满意点「换一个」。
- 满意就点「就去这家」：有本地行程就排进去；没有的话，会新建一个「这周六」的行程。

### 11. 撤销和放下

- 几乎每个操作之后，底部都会出现一条提示，6 秒内可以点「撤销」。
- 不想去的地方用「不想去了」放下，不会被删掉，在想去页的「已放下」里能找回来。

## 适合用在哪些地方

| 场景 | 怎么用 |
| --- | --- |
| **年假出国** | 平时刷到就往投递口一扔。攒够了在「按地方」里看哪一片最多，排一次行程，然后跟着车票上的检票孔一格格做完 |
| **本地探店** | 路过的店、同事推荐的馆子都记成「本地」。周末打开「帮我挑一个」，去完盖章，写一句好不好吃。同一家可以「又去了一次」 |
| **追季节** | 记地点时写上最佳月份（红叶、樱花、极光、鲁冰花、蟹粉季）。到了那个月，首页会提醒你；如果正好有一次行程去那一带，会建议你顺路加进去 |
| **和朋友商量行程** | 微信群里讨论了一晚上？复制聊天记录，贴进一键整理，地点、哪天去哪、要抢的票、要改的预算一次理清 |
| **有截止时间的事** | 抢票、办签证、换汇、预约门票，都写成带日期的准备事项。快到期时首页会提醒，最急的那条标红 |
| **旅行当天** | 打开「今天」：现在去哪、下一站还有多久、怎么去；门口要出示确认号就点一下；每到一处盖个章，顺手记花销 |
| **旅行日记** | 回来以后，在回忆页把盖过章的地方一个个补上感受、评分和照片 |
| **清理清单** | 首页会冒出「一年多没动了，还想去吗？」，想清楚就放下，清单保持新鲜 |
| **带家人出游** | 准备事项里列清楚谁要带什么（比如「给外婆的健康御守」）；备注里记下大家的约定 |

## 实用示例

### 示例 1：刷到一条小红书，十秒收进清单

1. 在小红书里点「分享 → 复制链接」，复制下来的文字大概是这样：
   ```
   https://www.xiaohongshu.com/explore/66f2a1c0 京都哲学之道｜秋天散步路线
   ```
2. 回到远方清单，粘贴进首页的投递口。下面会提示：`↵ 记下「哲学之道」· 自然 · 京都 · 来自小红书`。
3. 按回车。提示条上会出现「加进红叶七日」（因为你有一次去关西的行程），点一下就能直接选哪天。

### 示例 2：把一晚上的微信群聊变成行程

1. 在微信里多选聊天记录，复制。
2. 粘贴进首页投递口，按回车。内容比较长，会自动跳到「一键整理」，交给 AI 去拆。
3. 看右边的五个格子：
   - 「南禅寺 · 水路阁」标着**合并**：清单里已经有了，不会重复。
   - 「Day 4 · 14:02 嵯峨野小火车」标着**更新**：补上了「4 号车厢是露天的」。
   - 「抢嵯峨野小火车 14:02 那班」是**准备 · 合并**：给原来那条准备事项补上了截止时间。
4. 把不需要的勾掉，点「写入 N 条」。不满意就点提示条上的「撤销」。

> 没有配置 AI 服务商时，示例服务商只能整理示例那段聊天。想整理别的内容，先看示例 10。

### 示例 3：从零规划一次出国旅行

以「京都 · 大阪 红叶七日」为例：

1. **攒地点**：平时把伏见稻荷、岚山竹林、南禅寺……陆续记进来，城市写京都，它们会自动归到「关西」。
2. **建行程**：想去 → 按地方 → 关西 → 「排一次行程」。填名字「红叶七日」、日期 11.20–11.26、预算、同行。这几处想去会自动放进来。
3. **跟着检票孔走**：
   - 定日期：建的时候已经填了，自动生成 7 天。
   - 订交通：点它，加一项预订，类型选「机票」，写 `MU729 浦东 → 关西`、时间、确认号、金额。
   - 订住宿：同样加民宿或酒店。时间写成 `11.21 – 11.26 · 5 晚`，出发后「今天」页每天都会显示它。
   - 排日程：从「还没排进来」的候选里给每处选一天，或者在每天底下写 `06:30 伏见稻荷大社`。再给每天写个主题。
   - 准备：`11.01 抢永观堂夜枫门票`、`11.10 前换好日元`、`买旅行保险`……到期前会出现在首页。
4. **收攻略**：攻略标签页里点「收藏一篇攻略」，粘贴分享文字。
5. 车票上的检票孔全部打穿，就可以出发了。

### 示例 4：周末不知道去哪

1. 首页「下一步」里有「这周末去哪？」，或者在想去 → 按地方 → 你的城市，点「帮我挑一个」。
2. 选「吃饭」，看抽到哪家，不想去就「换一个」。
3. 点「就去这家」：已经有本地行程就排进去；没有的话，会自动建一个「这周六」的行程。
4. 去了之后在行程里或地点抽屉里点「到了，盖章」，写一句「红烧肉偏甜，下次早点去排队」。

### 示例 5：管住有截止时间的事

在行程的「准备」里这样写，日期会被认出来：

```
11.03 10:00 抢嵯峨野小火车票     → 截止 11 月 3 日 10:00
11.10 前换好日元                 → 截止 11 月 10 日
1.20 前办好签证                  → 截止明年 1 月 20 日（今年的已经过了）
买旅行保险                       → 没有截止时间
```

7 天内到期的会出现在首页「下一步」里，明天就到期的那条会标红。做完了直接在首页点「做完了」。

### 示例 6：出发当天

1. 早上打开，首页会显示「今天是『红叶七日』第 3 天」，点「打开今天」。
2. 看「现在」卡片：`10:30 坂道咖啡 · 还有 25 分钟 · 怎么去：京阪电车 + 步行`。点「导航过去」会打开地图。
3. 到了，点「到了，盖章」，写一句「拿铁一般，但窗外的八坂塔很好看」，打 4 分，花费填 `680`、选「円」。
4. 晚上去永观堂，门口点「出示预订」，把大字确认号给工作人员看。
5. 午饭花了 1,350 円，在「今天花了」里填金额、选「吃饭」、点「记一笔」。

### 示例 7：回来以后补回忆

1. 打开「回忆」，最上面列着「3 处去过，还没写回忆」。
2. 一处一处点「现在写」：一句话、评分、花费、照片（照片会压缩后保存）。
3. 写完的会变成明信片，按年份排好。以后翻到，就知道那天是什么感觉。

### 示例 8：清理很久没动的想去

首页偶尔会出现「伊斯坦布尔 · 2025.07 记下的，一年多没动了」：

- 还想去：点「还想去」，它会重新计时。
- 不想了：点「放下」，从清单里收起来，但不会删除，以后想去了还能在「已放下」里找回来。

### 示例 9：看看一天的路线排得顺不顺

京都 Day 3 排了伏见稻荷 06:30、坂道咖啡 10:30、清水寺 13:00、永观堂 17:30。

1. 在行程页 Day 3 底部点「在地图上看这天」。
2. 地图转到细看，四个地方按 1–4 连成一条红色虚线。右边写着：坂道咖啡 ↑ 3.6 公里、清水寺 ↑ 560 米、永观堂 ↑ 2.4 公里，一共约 6.5 公里。
3. 如果某一段超过 8 公里，下面会提醒你。回到行程页，把卡片拖到别的时间或别的一天，再看一次。

顺手看一下：锦市场就在附近，但它被放在 Day 2。如果 Day 3 的下午还有空，可以考虑挪过来。

### 示例 10：接上自己的 AI（以 DeepSeek 为例）

1. 在 DeepSeek 开放平台创建一个 API Key。
2. 打开「设置 → 添加服务商」：

   | 字段 | 填什么 |
   | --- | --- |
   | 名称 | `DeepSeek` |
   | 接口地址 | `https://api.deepseek.com/v1` |
   | 模型 | `deepseek-chat` |
   | 密钥 | 你的 `sk-...` |

3. 点「测试连接」，显示「连接正常」后点「保存」，它会自动设为启用。
4. 其他兼容 OpenAI 接口的服务填法一样。比如通义千问的地址是 `https://dashscope.aliyuncs.com/compatible-mode/v1`，Kimi 的是 `https://api.moonshot.cn/v1`。

> 如果测试时提示「连不上服务商」，可能是这家服务商不允许浏览器直接调用（跨域）。可以换一个支持跨域的中转地址。

### 示例 11：换电脑、备份

1. 旧电脑：「设置 → 数据 → 导出备份」，得到一个 `远方清单-备份-日期.json`。
2. 新电脑：打开远方清单，「设置 → 数据 → 导入备份」，选这个文件。
3. 建议每次旅行回来都导出一次，存到网盘里。

## 常见问题

**数据存在哪？会丢吗？**
存在你打开它的那个浏览器里，不会上传到任何地方。下面几种情况会导致数据丢失或看不到：

- 清理浏览器数据；
- 用无痕模式打开；
- 换了一个浏览器。

所以要定期导出备份。设置页会显示现在存了多少东西；如果浏览器不让存，那里会直接提醒你。

**能在手机上用吗？**
界面专门为手机做过，底部有底栏，中间是「+」。不过直接在手机上打开 html 文件，各家浏览器支持得不一样。更稳的办法是把项目放到一个网址上，比如 GitHub Pages：把 `yuanfang` 文件夹推到一个仓库并开启 Pages，手机打开那个网址就行。数据还是存在各自的设备上，两台设备之间用导出、导入备份来同步。

**AI 会花钱吗？**
用的是你自己的服务商账号，按它的价格计费。整理一段几百字的聊天，一般只用很少的 token。

**为什么 AI 连不上？**
设置页的「测试连接」和整理页的出错提示都会说明原因：

- 密钥不对；
- 地址不对（一般以 `/v1` 结尾）；
- 额度用完了；
- 服务商不允许浏览器直接调用（跨域）。

另外，在线预览页本身不允许访问外部网站，要下载到本地打开才能用。

**细看地图是空白的？**
街道底图是从高德或 CARTO 的服务器实时加载的，需要联网。没联网，或者在不允许外部请求的页面里（比如在线预览）打开，就只有地点和路线、没有街道。地图上方会出现一条说明。下载到本地、联网打开就好。

**高德和 CARTO 有什么区别？**
高德的地名是中文，国内的路网和店铺更全；国外的数据比较粗。CARTO 用的是 OpenStreetMap，国外的街道很细，地名一般是当地文字。默认「自动」会按地图中心在不在国内来选。另外，国内地图用的坐标和 GPS 坐标有几百米的偏差，切到高德时会自动换算，点选位置存下来的也是 GPS 坐标，不用管它。

**示例数据里的日期怎么过期了？**
示例是 2026 年 11 月的一次京都行程。过了那个时间，它会显示成「已完成」。示例只是用来看效果的，清空以后记你自己的就行。

**能多人一起用吗？**
现在不能。它是一个人用的本子。和同行的人可以通过一键整理同步聊天里的内容，或者把备份文件发给对方导入。
