# 远方清单 · 界面演示

把零散的「想去」逐步变成真的发生过的旅行。

这是演示版：只有界面和交互，没有后端，数据全部来自 `data.js`，刷新页面就会恢复原样。

## 打开方式

直接双击 `index.html` 即可；或者在这个目录里起一个本地服务：

```bash
python3 -m http.server 8000
```

然后访问 http://localhost:8000 。字体从 Google Fonts 加载，需要联网。

## 设计思路

整套界面借用邮政和旅行票据里的物件，让数据在「想去 → 计划中 → 已去过 → 回忆」这条链上流动时，看得出它变成了什么：

| 状态 | 物件 | 页面上的表现 |
| --- | --- | --- |
| 想去 | 邮票 | 每个地点是一枚两色套印的邮票，面值就是想去程度（1–5 分） |
| 计划中 | 车票 | 邮票角上夹一张车票签，写着排在哪次行程的第几天；行程本身是一张登机牌 |
| 已去过 | 邮戳 | 盖上带日期的圆形邮戳 |
| 回忆 | 明信片 | 贴着照片（带相角和胶片日期）的明信片，背面手写评价、花费 |

地图上同样用形状区分状态：○ 想去、◆ 计划中、◉ 已去过。

## 七个页面

地址栏的 `#` 后面就是页面名，可以直接收藏或分享：

- `#home` 总览：倒计时、四个阶段的数量、下一次出发、出发前待办、最近记下的地点
- `#places` 想去：地点库，可按远方/本地、类型、状态筛选，按想去程度/最近记下/名称排序；悬停可「加入行程」或「标记去过」（会盖邮戳）
- `#trip` 行程：行程车票、每天的时间轴（Day 1、Day 2…）、资料夹（准备 / 攻略 / 预订 / 备注）
- `#map` 地图：世界地图和上海本地示意图，按状态着色，虚线是计划中的航线
- `#memories` 回忆：按年份排列的明信片，以及「去过但还没写回忆」的提醒
- `#sort` 一键整理：粘贴聊天记录，演示拆成 行程信息 / 地点 / 日程 / 资料 / 回忆 五类，勾选后写入
- `#providers` 设置：AI 服务商（名称、接口地址、模型、密钥），可切换启用哪一个

左下角的邮票形「+」按钮可以随时「记下一个想去」，填写时预览邮票会跟着变化。

## 文件

```
index.html   页面骨架、导航、对话框、邮戳与印章的 SVG 滤镜
styles.css   全部样式；配色、字体等设计令牌在文件开头，含深色模式
app.js       渲染与交互；邮票图案、邮戳都是代码画的 SVG
data.js      演示数据，结构对应 places / trips → trip_days → trip_items / materials / memories / ai_configs
world.js     世界陆地轮廓（Natural Earth 110m，经 world-atlas，已预先投影）
```

## 做成真实版本时

- 地图：演示里是自绘的静态 SVG，接后端后可以换成 Leaflet，沿用同样的三色、三种形状的标记。
- 一键整理：`data.js` 里的 `aiResult` 就是界面期望的返回结构，可以直接作为让模型输出的 schema 参考。
- 字体：标题用站酷小薇，但它的「回」字轮廓有问题，`index.html` 里单独为这个字补了 Noto Serif SC。
