# 远方清单

把零散的「想去」逐步变成真的发生过的旅行。

一个自己用的旅行心愿单 + 行程规划。纯前端，打开 `index.html` 就能用：数据存在本机浏览器里，「一键整理」会调用你自己配置的 AI 服务商。

## 打开方式

直接双击 `index.html`；或者在这个目录里起一个本地服务：

```bash
python3 -m http.server 8000
```

然后访问 http://localhost:8000 。字体从 Google Fonts 加载，需要联网。

第一次打开会载入一份示例数据（一次京都红叶行、几家上海的店），方便先看效果。准备好了，在首页顶上或「设置 → 数据」里点「清空，从零开始」。

## 它到底要解决什么

想去的地方从来不缺，缺的是一步步把它变成真的出发。所以这个网站不是收藏夹，它关心的是「下一步做什么」：

- **记的时候要零成本**：首页的投递口、或任何页面按 `/`，输入名字回车就存；城市、类型自动猜，常见城市自动给坐标。粘贴小红书分享文字会认出地点和来源；一整段聊天记录交给 AI 分拣。已经记过的会先提示，避免重复。
- **首页是「下一步」**：每一条都写明它把什么从哪一格推到哪一格（○ 想去 → ◆ 计划中 → ◉ 已去过 → ■ 回忆），按急不急排序：快到期的准备事项、季节正好又顺路的地点、还没定日期的行程、攒够了几处的地方、去过还没写回忆的、一年多没动的想去……不想现在处理的点「稍后」，一周后再出现。
- **行程的进度是算出来的**：车票下面一排检票孔——定日期、订交通、订住宿、排日程、准备——由你填的内容自动判断，不用手填百分比；下一个没完成的那一格可以直接点，带你去完成它。
- **出发那天**：「今天」页显示现在这一项、下一项还有多久、怎么去（链接到高德或 Google 地图）、当天要用的预订（大字出示确认号）、今天花了多少。到了一处点「盖章」，顺手写一句、打分、加照片，就从「已去过」走到了「回忆」。行程日期到了会自动切换；没出发时可以用示例预览。
- **随时能反悔**：所有改动都能撤销；不想去的地方「放下」而不是删除。

## 一键整理

把聊天记录、攻略正文贴进来，AI 按固定格式拆成五类：行程信息（trip_patch）、地点（places）、日程（items）、资料（materials）、回忆（memories）。已经存在的地点、日程、准备事项会合并，不会重复创建；每条都能勾掉，确认后一次写入，写入后也能撤销。

在「设置」里添加 OpenAI 兼容的服务商（DeepSeek、通义千问、Kimi、自建中转等）：名称、接口地址（一般以 `/v1` 结尾）、模型、密钥。可以添加多个，切换启用哪一个。

需要知道的几点：

- 浏览器会直接请求服务商的 `/chat/completions`，密钥只存在这台设备的浏览器里。只在自己的设备上用。
- 有些服务商不允许浏览器直接调用（跨域）。遇到这种情况，页面会说明原因；可以换一个支持跨域的中转地址，或者以后加一个后端代理。
- 在线预览页不允许访问外部网站，所以那里只能用示例结果；下载到本地打开就能真的调用。
- 截图和链接：浏览器里还不能识别图片，也读不到网页正文。截图请先用手机的「提取文字」，链接请复制正文贴进来。

## 数据

- 存在浏览器的 localStorage 里（键名 `yuanfang/v3`）。换设备、清理浏览器数据之前，在「设置 → 数据」里导出一份备份（JSON），之后可以导入。
- 照片会压缩到长边 900 像素再存，避免占满浏览器的存储空间。
- 结构对应后端的表：`places` / `trips` → `days` → `items` / `materials` / `memories` / `providers`（即 ai_configs）。`places` 比最初的设想多了几个字段：`area`（同一趟能顺路去的归在一起）、`season` / `seasonNote`（最佳季节）、`note`（为什么想去）、`src`（从哪里看到的）、`dropped`（不想去了）。
- 行程的状态（草拟 / 计划中 / 进行中 / 已完成）和进度不单独存，由日期和内容推算。

## 页面

地址栏 `#` 后面就是页面名，可以收藏：

- `#home` 总览：投递口、下一步、下一次出发、四个阶段
- `#places` 想去：邮票册（筛选、排序、搜索）和按地方看（攒够了一键排行程）
- `#trip` 行程：车票和里程碑、候选地点、每天的安排（可加、可拖、可删）、资料夹（准备 / 攻略 / 预订 / 备注，都能增删）
- `#today` 今天：旅行当天的安排、预订、记账、盖章
- `#map` 地图：三种看法。总览是世界地图，按状态着色，虚线是计划中的航线；细看是可以缩放到街道的瓦片地图，能按地区跳转、把某一天的地点连成路线、在地图上点选位置；本地是家所在城市的示意图
- `#memories` 回忆：待回填的地方 + 按年份的明信片，可以改、可以删
- `#sort` 一键整理
- `#providers` 设置：AI 服务商、家在哪个城市、数据备份

快捷键：`/` 或 `n` 打开「搜索，或记下一个想去」；在框里 `↑↓` 选择、`↵` 确定、`tab` 展开详情再存。首页投递口里 `↵` 投递，`⇧↵` 换行。

## 设计

整套界面借用邮政和旅行票据：想去的地点是邮票（面值就是想去程度），计划是车票，去过盖邮戳，回忆是贴了照片的明信片，首页的输入框是一个航空信封样式的投递口。形状也编码状态，在标签、地图、手机底栏里都一致：○ 想去、◆ 计划中、◉ 已去过、■ 回忆。
