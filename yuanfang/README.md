# 远方清单 · 界面演示

把零散的「想去」逐步变成真的发生过的旅行。

这是演示版：只有界面和交互，没有后端，数据全部来自 `data.js`，刷新页面就会恢复原样。

## 打开方式

直接双击 `index.html` 即可；或者在这个目录里起一个本地服务：

```bash
python3 -m http.server 8000
```

然后访问 http://localhost:8000 。字体从 Google Fonts 加载，需要联网。

## 从使用场景出发

一个人用这个网站，大致会经历五种时刻。每种时刻的频率、设备和心态都不一样，界面按这个来安排：

| 时刻 | 频率 / 设备 | 用户要的是什么 | 界面怎么接住 |
| --- | --- | --- | --- |
| 随手记 | 最频繁，多在手机上 | 刷小红书、听朋友推荐时立刻记下，别打断我 | 任何页面按 `/`（手机点底栏正中的「+」）打开同一个输入框：输入名字回车就存，类型和城市自动猜；粘贴链接会识别成地点；已经记过的会先列出来，避免重复 |
| 挑下一次去哪 | 偶尔，周末翻一翻 | 想去的太多，不知道先去哪 | 「想去」可以按地方归组，攒够几处就提示「够专门跑一趟了」并一键建行程；总览里有「这个月正是时候」，按每个地方的最佳季节挑；本地店选不出来就「帮我挑一个」（想去程度越高越容易抽中） |
| 排行程 | 低频但很费功夫，多在电脑上 | 把想去的地点排进具体某一天 | 行程页顶上列出「这个地方还有几处想去没排进来」，选一天就加；每天底下能直接打字加一项（`15:30 平等院` 会自动认出时间和清单里的地点）；拖动调整顺序 |
| 旅行当天 | 集中几天，全在手机上 | 现在该干嘛、下一站在哪、确认号在哪 | 「今天」页：现在这一项、下一项还有多久、怎么去；预订一键「出示」大字确认号；到了点「盖章」，顺手写一句、打分、记花费、加照片，这一步就是「已去过 → 回忆」 |
| 回来以后 | 偶尔 | 趁还记得补回忆，别丢 | 回忆页把「去过还没写」的地方列在最上面，一处一分钟 |

几条贯穿全站的约定：

- **每一枚邮票都能点**，打开同一个地点抽屉。抽屉顶上是这个地方在「想去 → 计划中 → 已去过 → 回忆」上走到了哪一步，下面最显眼的按钮就是下一步。
- **改了什么都能撤销**：提示条上带「撤销」，6 秒内有效。
- **不删除，只放下**：不想去的地方点「不想去了」，在想去里的「已放下」能找回来。
- **不打扰**：没填的字段不追问，季节、标签、原因都可以以后在抽屉里补。

## 设计思路

整套界面借用邮政和旅行票据里的物件，让数据在状态链上流动时，看得出它变成了什么：

| 状态 | 物件 | 页面上的表现 |
| --- | --- | --- |
| 想去 | 邮票 | 每个地点是一枚两色套印的邮票，面值就是想去程度（1–5 分） |
| 计划中 | 车票 | 邮票角上夹一张车票签，写着排在哪次行程的第几天；行程本身是一张登机牌 |
| 已去过 | 邮戳 | 盖上带日期的圆形邮戳 |
| 回忆 | 明信片 | 贴着照片（带相角和胶片日期）的明信片，背面手写评价、花费 |

形状也编码状态，在标签、地图、手机底栏里都一致：○ 想去、◆ 计划中、◉ 已去过、■ 回忆。

## 页面

地址栏的 `#` 后面就是页面名，可以直接收藏或分享：

- `#home` 总览：倒计时、四个阶段、下一次出发、出发前待办、这个月正是时候、最近记下的、城里想去的
- `#places` 想去：「邮票册」可筛选排序；「按地方」看哪里攒够了
- `#trip` 行程：车票、候选地点、每天的时间轴（可加一项、拖动、移除）、资料夹（准备 / 攻略 / 预订 / 备注）
- `#today` 今天：出发当天的样子（演示里假设是 11 月 22 日）
- `#map` 地图：世界地图和上海本地示意图，按状态着色，虚线是计划中的航线
- `#memories` 回忆：待回填的地方 + 按年份排列的明信片
- `#sort` 一键整理：粘贴文字 / 聊天截图 / 攻略链接，拆成五类，已存在的条目会合并
- `#providers` 设置：AI 服务商（名称、接口地址、模型、密钥），可切换启用哪一个

快捷键：`/` 或 `n` 打开「搜索，或记下一个想去」；在框里 `↑↓` 选择、`↵` 确定、`tab` 展开详情再存。

## 文件

```
index.html   页面骨架、导航、浮层容器、邮戳与印章的 SVG 滤镜
styles.css   全部样式；配色、字体等设计令牌在文件开头，含深色模式
app.js       渲染与交互；邮票图案、邮戳都是代码画的 SVG
data.js      演示数据，结构对应 places / trips → trip_days → trip_items / materials / memories / ai_configs
world.js     世界陆地轮廓（Natural Earth 110m，经 world-atlas，已预先投影）
```

## 做成真实版本时

- 数据：`places` 比原始设想多了几个字段——`area`（按地方归组）、`season` / `seasonNote`（最佳季节）、`note`（为什么想去）、`src`（从哪里看到的）、`dropped`（不想去了）。
- 地图：演示里是自绘的静态 SVG，接后端后可以换成 Leaflet，沿用同样的三色、三种形状的标记。
- 一键整理：`data.js` 里的 `aiResult` 就是界面期望的返回结构；`match` 字段表示识别出已存在的条目，写入时应合并而不是新建。
- 字体：标题用站酷小薇，但它的「回」字轮廓有问题，`index.html` 里单独为这个字补了 Noto Serif SC。
