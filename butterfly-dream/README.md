# 《栩栩》 *Whose Dream* —— 动画短片设计案

> 昔者庄周梦为胡蝶，栩栩然胡蝶也，自喻适志与！不知周也。俄然觉，则蘧蘧然周也。不知周之梦为胡蝶与，胡蝶之梦为周与？周与胡蝶，则必有分矣。此之谓物化。
>
> ——《庄子·齐物论》

片名取自「栩栩然胡蝶也」。「栩栩」是蝴蝶翩然自在的样子，也让人想到「栩栩如生」：两个世界里，到底哪一个才是活的？

配套的**动态分镜预览**见 [`animatic.html`](./animatic.html)（用浏览器打开即可播放，详见第 11 节）。

## 0. 基本信息

| 项目 | 内容 |
|---|---|
| 片名 | 《栩栩》 / *Whose Dream* |
| 时长 | 正片 2′45″；加上片尾字卡和彩蛋共 3′00″ |
| 类型 | 实验、诗意短片，无对白（适合国际短片节） |
| 形式 | **2D 手绘**（黑白、雨、都市）× **3D 渲染**（彩色、晴、花野） |
| 画幅 | 2D 世界 **4:3**，3D 世界 **2.39:1**，结尾两界交汇时 **16:9** |
| 动画节奏 | 2D 一拍二（12 fps，机械、顿挫），3D 一拍一（24 fps，流畅，带运动模糊） |
| 主角 | **周**：三十岁上下的写字楼职员<br>**碧凤蝶**（*Papilio bianor*）：中国常见的凤蝶，翅面有会随角度变色的翠绿和宝蓝鳞片 |

## 1. 一句话梗概

一个在黑白雨城里日复一日上班的人，下午三点在工位上打了个盹，梦见自己变成一只蝴蝶，在彩色的晴天里度过了绚烂又短暂的一生。他醒来时，办公室的窗玻璃**外侧**留着一枚彩色的蝶形鳞粉印。

## 2. 故事梗概

清晨六点，雨。周从裹成茧状的被子里伸出手按掉闹钟，对镜把领带推上喉咙，在一片齐步行进的黑伞里过斑马线，从塞满同一张脸的地铁里被挤出来，坐进一望无际的格子间。他工位隔板上钉着一只蝴蝶标本，在这个世界里它也是灰的。时钟、键盘、表格、盖章……重复越来越快。下午三点，他盯着标本，头一点一点地砸在了键盘上。

镜头扎进屏幕上的表格，格子弯曲、层叠，泛出虹彩，原来是蝶翅上的鳞片。一只碧凤蝶在黎明破蛹而出。它展开翅膀的同时，画面的黑边也向两侧退开。它第一次起飞，掠过花海，与另一只蝴蝶螺旋着飞进太阳。正午它停在花上合翅小憩，却被闪回的黑白办公室惊醒：它梦见了一个上班的人。午后它被一扇立在草地中央、没有墙的窗吸引，一头撞上玻璃。玻璃另一边是黑白的、正趴在键盘上熟睡的周。

黄昏，它产下几颗卵，拖着破损褪色的翅膀最后一次飞向落日，然后合上翅膀。画面的黑边也随之合拢。

黑暗里手机响了，铃声正是蝴蝶的那段旋律。深夜，周醒来，看见窗玻璃外侧那枚彩色的蝶形印，雨水正把颜色一道道冲下来。他没有拿伞，走进夜雨。在一个水洼前，他低头看见的不是自己，而是正午的晴空，和一只正在看他的蝴蝶。画面翻转过来，没人分得清哪一边才是倒影。

## 3. 核心设计理念

### 3.1 两个世界

| | **周的世界：雨** | **蝶的世界：晴** |
|---|---|---|
| 维度 | 2D 手绘，扁平，正面，对称 | 3D 渲染，纵深，微距，浅景深 |
| 色彩 | 纯黑白灰，最多三个灰阶，加纸纹颗粒 | 高饱和全彩，色温随一天变化 |
| 天气 | 永远在下雨（雨线 = 排线 = 栅栏） | 永远是晴天（光线 = 光束 = 道路） |
| 画幅 | 4:3，像格子间一样窄 | 2.39:1，像张开的翅膀一样宽 |
| 动画 | 一拍二 12 fps，线条轻微抖动 | 一拍一 24 fps，丝滑，带运动模糊 |
| 镜头 | 固定机位、正面、俯拍，人物常被框在门、格子和窗里 | 永远在飞，跟拍、环绕、仰拍，摄影机像另一只蝴蝶 |
| 节奏 | 节拍器式，被量化的重复 | 自由节奏，呼吸式 |
| 声音 | 闹铃、键盘、钟、打印机，近、干、满 | 古琴、风、鸟、振翅，远、湿、空 |
| 时间 | 一个工作日 | 一生 |

### 3.2 一天就是一生

人的一个工作日和蝶的一生是同一个结构：

| 周的一天 | 蝶的一生 |
|---|---|
| 清晨，从茧状的被子里醒来 | 黎明，破蛹 |
| 被挤出地铁门 | 挤出蛹壳 |
| 上午，在斑马线上走格子 | 上午，第一次飞 |
| 午后打盹 | 正午合翅小憩 |
| 加班到深夜 | 黄昏，衰老 |
| 趴在桌上睡去 | 合上翅膀死去 |

周打盹的那几个小时（15:00 到深夜），刚好是蝴蝶从生到死的全部。

### 3.3 画幅就是翅膀

4:3 的窄框像格子间。蝴蝶展翅时，左右黑边跟着翅膀一起向两侧推开，画面变成 2.39:1；它临死合翅时，黑边再合拢回来。观众会看见画框在「呼吸」。结尾水洼段，画幅停在两者之间的 16:9，也就是两个世界的中间态。

画幅动画在合成阶段完成，用驱动器（driver）绑定到蝴蝶翅膀的展开曲线上，保证两者完全同步。

### 3.4 结构色：颜色取决于角度

碧凤蝶的翅面是黑底上撒满翠绿、宝蓝的鳞片。这是**结构色**，颜色会随观看角度变化。合起翅膀时，露出来的反面却是灰褐色的。

所以：**展翅是彩色的世界，合翅就是灰色的世界。**颜色不在翅膀「里面」，而在「看的角度」里。哪边是梦，也取决于你站在哪一边看。

### 3.5 唯一越界的颜色

全片的 2D 段落只允许出现一种颜色：碧凤蝶的「碧」（`#19C3B0` 到 `#2A6FDB` 的渐变）。它只出现三次：

1. **S07**：日光灯闪烁时，有 2 帧是闪着碧色光泽的鳞片（潜意识，观众几乎察觉不到）。
2. **S19**：窗玻璃上的鳞粉印，也是梦留下的物证。
3. **S21**：水洼里的倒影。

反过来，3D 段落也只允许出现一次灰：**S13** 合翅午憩时，翅膀灰褐色的反面，以及闪回的 2D 办公室噩梦。

### 3.6 同一段旋律，两种音色

全片只有一个主题动机：D 宫五声音阶的七个音 **A – B – D – B – A – F♯ – E**（徵羽宫羽徵角商），先升后落，像一次振翅。

- 在周的世界里，它是**闹钟和手机铃声**，方波电子音，刺耳、急促。
- 在蝶的世界里，它是**古琴**，自由、缓慢、有余韵。
- 在结尾（S21），两种音色第一次同时奏出。

观众到后来会意识到：叫醒周的铃声，就是蝴蝶的歌。

### 尾声「觉」：2D · 黑白（加一抹碧色）

## 7. 美术设计

### 7.1 2D 黑白世界

- **线条**：参考中国画白描和版画，用干涩的墨线勾形，线条在每一帧轻微「抖动」（line boil），让画面有一种不安。
- **灰阶**：只用三个值：墨黑 `#141414`、中灰 `#7C7B77`、纸白 `#E7E5DF`，叠加纸张颗粒。
- **雨**：用斜向的平行排线表现，铺满画面。雨线既是天气，也是栅栏，还是格子间的隔板线。
- **人物**：路人没有五官，由同一个模板复制而成。周有脸，但只有两道代表眼睛的短线。
- **构图**：正面、对称、居中；大量使用门框、格子、窗框，把人物「框」在里面。
- **运动**：一拍二，动作被量化成「走格子」，像节拍器。

### 7.2 3D 彩色世界

- **风格**：风格化写实，带微距摄影的质感，比如浅景深、焦外光斑、镜头光晕；材质略带手绘笔触，避免过于「CG」。
- **蝴蝶**：碧凤蝶，黑底翅面上撒满翠绿、宝蓝的结构色鳞片，后翅有红色眼斑和尾突。翅面 shader 用薄膜干涉，或基于视角的 Fresnel 色相偏移，让翅膀转动时颜色流动。翅膀反面是灰褐色，带浅色条带。
- **第二只蝴蝶**：同一物种，色相偏金绿，便于在 S12 的螺旋里区分。
- **花海**：6 到 8 种花（波斯菊、虞美人、金鸡菊、矢车菊等），用几何节点散布、实例化；每朵花有独立的摆动相位（对照 S04 的齐步）。
- **超现实的窗**：一扇白漆木窗框，没有墙，立在草地上。外侧玻璃反射天空，内侧是 2D 世界。可参考马格利特的超现实构图。

### 7.3 色彩剧本

3D 世界的一天，就是蝴蝶的一生，色彩跟着生命阶段走：

| 阶段 | 镜号 | 主色 | 情绪 |
|---|---|---|---|
| 黎明 · 幼 | S09–S10 | 粉 `#F3C6C0`、杏 `#FBE3C4`、嫩绿 `#D9E6C3` | 柔软、初生 |
| 正午 · 盛 | S11–S12 | 天蓝 `#2F8EE0`、朱红 `#FF5A3C`、明黄 `#FFD23F`、品红 `#E84393` | 饱和、自由、爱 |
| 午后 · 熟 | S13–S14 | 暖绿 `#BFE3A0`、橙 `#FF8A3D` | 慵懒、恍惚 |
| 黄昏 · 老 | S16 | 绛紫 `#2A1E4F`、玫红 `#B8456A`、橘 `#F08A4B`、金 `#FFCF7A` | 燃烧、告别 |
| 入夜 · 逝 | S17 | 琥珀到全黑 | 熄灭 |

2D 世界始终是黑白，唯一例外是「碧」（`#19C3B0` 到 `#2A6FDB`），见 3.5。

### 7.4 角色

**周**
- 三十岁上下，瘦，微驼，白衬衫、黑领带、深灰外套。
- 脸上只有两道代表眼睛的短线；睁眼、困倦、闭眼三种状态即可。
- 关键姿态：茧状蜷缩（S02）、被挤压变形（S05）、趴睡（S08/S15）、仰面淋雨（S20）。他的姿态和蝴蝶的姿态一一对应。

**碧凤蝶**
- 需要的形态：蛹（完整、开裂、空壳）、湿皱的初生翅、完全展开、合翅（反面）、破损褪色的老年翅、卵。
- 绑定：翅膀用 4 块骨骼（前后翅各一）加形变器，处理初生时的皱缩和展开；破损用 alpha 遮罩的 blendshape。
- 飞行：真实的蝴蝶振翅约每秒 5 到 10 次，这里按情绪调整：初飞时乱，相遇时慢，临死时极慢。

## 8. 声音与音乐

| 元素 | 周的世界 | 蝶的世界 |
|---|---|---|
| 主题 | 方波电子音（闹钟、手机铃） | 古琴为主，箫、竖琴、弦乐 |
| 节奏 | 被量化到网格的机械节拍（120 渐快到 160 BPM） | 自由节奏，呼吸式 |
| 环境 | 持续的白噪雨声，空调，地铁 | 风，鸟，虫鸣，振翅的「呼—」 |
| 低频 | 大提琴长音（压抑） | 无（空） |
| 空间 | 近、干、满 | 远、湿（长混响）、空 |

**交织的四个声音瞬间：**

1. **S09**：键盘声越敲越慢、混响越来越长，变成古琴泛音。
2. **S13**：闪切时，机械节拍和雨声硬生生插进古琴里。
3. **S15**：左声道是蝶的世界，右声道是周的世界，玻璃就是声场的分界线。
4. **S21**：主题由电子音和古琴同时奏出，两种音色第一次合在一起。

全片的首尾都是**同一滴水的声音**（S01 与 S22），中间的一切都可以理解为一滴雨落下的那一瞬间。

## 9. 结局的三种读法

影片不给标准答案，但给每种读法都留了证据：

1. **周梦蝶**：一个被生活压扁的人做了一个美梦。窗上的鳞粉印也许是他还没醒透的幻觉。但他决定不打伞走进雨里，所以梦改变了醒。
2. **蝶梦周**：彩色那边才是真实。蝴蝶在午憩时做了一个关于「上班」的噩梦（S13），整个黑白世界不过是一只蝴蝶临死前的走马灯。S21 翻转后的构图支持这个读法：黑白的那一边才是倒影。
3. **物化**：二者本是一体。人的一天和蝶的一生同构，一个闭眼，另一个就睁眼（S17 合翅，紧接 S18 铃响）。彩蛋里空掉的椅子和空掉的标本框说明，他们都「走了」；是自由还是消逝，留给观众。

## 10. 制作方案

### 10.1 推荐管线

**全片在 Blender 内完成**，2D 和 3D 共用同一个场景、同一台摄影机，这是 S09、S15、S21 三个跨界镜头能做到无缝的关键。

| 环节 | 工具 |
|---|---|
| 分镜 / 动态分镜 | Storyboarder 或 Procreate；节奏样片见 `animatic.html` |
| 2D 动画 | Blender Grease Pencil（可在三维空间中绘制），或 Toon Boom Harmony / TVPaint |
| 3D 建模、绑定、动画 | Blender（几何节点散布花海） |
| 渲染 | EEVEE 负责风格化的大部分镜头；Cycles 负责微距、焦散、露珠 |
| 合成 / 画幅动画 | Blender Compositor 或 Nuke / After Effects |
| 调色 | DaVinci Resolve |
| 音乐 / 声音 | 任意 DAW；古琴建议实录 |

### 10.2 团队与周期（最小配置 4 到 5 人，约 14 周）

| 周 | 工作 |
|---|---|
| W1–2 | 剧本定稿、分镜、动态分镜、色彩剧本、主题动机小样 |
| W3–5 | 美术设定；资产制作（周、人群模板、蝴蝶及其各形态、蛹、花海、窗框） |
| W6–10 | 动画（2D 与 3D 并行） |
| W8–11 | 灯光、渲染 |
| W11–12 | 合成；跨界转场；画幅动画 |
| W12–13 | 作曲、音效、混音 |
| W14 | 调色、字卡、输出（4K 母版，加节展用的 H.264 / DCP） |

人员：导演兼分镜 1 人；2D 动画 1 到 2 人；3D（建模、绑定、动画、灯光）1 到 2 人；作曲与声音设计 1 人（可外包）。

### 10.3 资产清单

- **2D**：周（正、侧、背面）、人群模板、卧室、镜子、斑马线、地铁、格子间、工位、夜街、窗；道具有闹钟、领带、黑伞、工牌、标本框、键盘、表格、衣架
- **3D**：碧凤蝶两只（含全部形态）、蛹（三态）、卵、花海（6 到 8 种花）、草叶、超现实窗框、水洼
- **跨界**：鳞粉印（2D 世界里唯一的彩色元素）、玻璃分屏装置、水线镜像装置

### 10.4 技术难点与对策

| 难点 | 对策 |
|---|---|
| 表格变鳞片的一镜到底（S09） | 用程序化着色器驱动网格形变（直线变弧线、行错位、灰度变虹彩），再接 3D 微距镜头 |
| 两个世界同框（S15、S21） | Grease Pencil 对象和 3D 对象放在同一场景，用遮罩分区渲染、统一合成 |
| 帧率差 | 2D 层设为 step 插值（一拍二），3D 层全帧加运动模糊；转场处逐步过渡 |
| 画幅动画 | 合成阶段做动态遮幅，用驱动器绑定到翅膀展开的参数上 |
| 花海的渲染量 | 几何节点实例化加 LOD，远景用面片 |
| 蝶翅结构色 | 薄膜干涉 shader，或基于视角的色相渐变贴图 |

## 11. 动态分镜预览 `animatic.html`

为了在正式制作前验证**节奏、画幅变化、色彩切换和声音转场**，本目录附带一个可以直接在浏览器里播放的 3 分钟动态分镜。

- **打开方式**：用浏览器打开 `animatic.html`，点击「播放」（建议打开声音）。
- **操作**：空格键播放或暂停；← → 键快退或快进 5 秒；点击或拖动时间轴跳转。
- **信息面板**：播放时实时显示当前镜号、时间码、画面、镜头和声音说明，与本文档的分镜脚本一一对应。
- **画面**：全片由 WebGL2 实时渲染的粒子构成（桌面 4 万个，手机 2.6 万个）。每个镜头的形状都由光点聚拢而成，镜头之间粒子会流动、重组；3D 段落带辉光、景深光斑（焦外的花变成彩色光圈），2D 段落是银灰色的光点加胶片颗粒，并按一拍二（12 fps）顿挫。
- **粒子语言与分镜的对应**：片名和片尾字卡由光尘逐字聚拢、再被风吹散；S17 蝴蝶死去时化作余烬般的光尘升起；S19 窗上的鳞粉印是一粒粒碧色粉末，被雨水冲着往下流。
- **声音**：由 Web Audio 实时合成（雨声、闹铃、古琴拨弦、鸟鸣）。
- **要求**：需要支持 WebGL2 的浏览器（新版 Chrome、Edge、Firefox、Safari 均可）。`animatic.html` 要和 `js/` 文件夹放在一起，双击即可离线打开（不联网时字卡用系统字体）。
- **说明**：动态分镜只用来参考节奏、画幅、色彩和声音，不代表最终美术效果。

| 文件 | 内容 |
|---|---|
| `animatic.html` | 页面与界面 |
| `js/engine.js` | WebGL2 渲染（粒子、辉光、景深、颗粒、画幅遮罩）与粒子系统 |
| `js/shapes.js` | 把剪影和文字采样成点云；3D 碧凤蝶、蛹、花海、光尘、雨 |
| `js/scenes1.js` ~ `scenes3.js` | 各镜号的画面（S01–S09、S10–S18、S19–E3） |
| `js/audio.js` | 声音合成与事件表 |
| `js/main.js` | 分镜表、画幅曲线、播放与时间轴 |
